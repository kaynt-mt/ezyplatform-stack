# Nghiên cứu EzyPlatform 1.5.9 cho plugin quản lý công việc

**Đích:** xác định phần có thể dùng lại từ EzyPlatform, phần plugin phải tự sở hữu, và những giả định cần thử trước khi xây sản phẩm kiểu Plane. Đây là nghiên cứu tài liệu/mã nguồn công khai, không phải báo cáo chạy thử. Hai tài liệu đi cùng: [thiết kế plugin](plane-plugin-design-notes.md) và [mục lục kiểm kê hướng dẫn](ezyplatform-guide-inventory.md).

## Kết luận

1. **EzyPlatform là runtime có thể mở rộng**, không phải chỉ CMS và cũng không mở toàn bộ mã nguồn. App mới nên nằm ở repo riêng, dựa trên core đã có; không fork core để thêm tính năng nghiệp vụ. [Giới thiệu](https://ezyplatform.com/ezyplatform-introduction) · [FAQ](https://ezyplatform.com/faq) · [README của stack](../../README.md).
2. **Dùng Admin để vận hành; dùng Web cho người quản lý dự án và thành viên.** Không cấp tài khoản Admin cho mọi thành viên để có giao diện nhanh. Core xác thực danh tính; quyền theo workspace, project và work item do plugin làm.
3. **Tự sở hữu schema công việc và hợp đồng API.** Tái sử dụng nền HTTP, media, i18n, notification/letter và pattern phân trang; không biểu diễn work item thành bài viết EzyArticle. EzyArticle chỉ là ứng viên tùy chọn cho tài liệu dự án.
4. **Chưa cần Socket cho MVP.** Cập nhật HTTP có phiên bản và tải lại trạng thái trước; thêm thông báo realtime sau khi có kiểm tra quyền cả lúc subscribe lẫn lúc phát.

## Runtime, module và công cụ

| Thành phần | Tài liệu nói gì | Dùng cho plugin |
| --- | --- | --- |
| Admin (mặc định 9090) | Nhiều Admin plugin hoạt động đồng thời; mở rộng menu, view và API. | Cấu hình tích hợp, tình trạng job và hỗ trợ, không dùng thay app làm việc. |
| Web (mặc định 8080) | Nhiều Web plugin cung cấp API hoặc tích hợp vào giao diện; chỉ một theme hoạt động tại một thời điểm. | Đóng gói API Web trước; kiểm tra cách mount app dưới theme đang dùng, không buộc đổi theme toàn site. Theme riêng là phương án cho instance chuyên dụng. |
| Socket | EzyFox Server: TCP/UDP/WebSocket; Socket Plugin thường xử lý login/tác vụ nền, Socket App xử lý request realtime. Token admin và user là hai loại khác nhau. | Không mở cổng nếu MVP không dùng; sau này ưu tiên WSS và không dùng subscription như nguồn dữ liệu duy nhất. |
| Dữ liệu và giao diện | EzyData/Hibernate/JPA/HikariCP; EzyHTTP/Jetty; Thymeleaf cho template, Bootstrap/jQuery trong giao diện mẫu. | Theo conventions của EzyHTTP và EzyData, không giả định có Spring Boot; chọn UI bàn việc độc lập với vòng đời theme sau spike tích hợp. |
| SDK dự án | Ví dụ `book-store` và `personal` có thành phần `*-sdk` dùng chung và các module triển khai; không có yêu cầu tạo thêm module `*-common` độc lập. | Giữ entity/repo/service, policy và DTO dùng chung ở `work-management-sdk`; tách controller, interceptor và asset theo runtime. |

Nguồn: [cấu trúc](https://youngmonkeys.org/ezyplatform/guides/ezyplatform-structure?lang=vi), [tech stack](https://youngmonkeys.org/ezyplatform/guides/ezyplatform-tech-stack?lang=vi), [theme và plugin](https://youngmonkeys.org/ezyplatform/guides/understanding-ezyplatform-themes-and-plugins?lang=vi), [cấu trúc project](https://youngmonkeys.org/ezyplatform/guides/the-structure-of-a-plugin-project?lang=vi).

- `module.properties` mô tả module triển khai; `menus.properties` dành cho Admin, `assembly.xml` là descriptor đóng gói, `src/main/resources/static` được publish, không chứa bí mật. Prefix route Admin có thể được gắn theo tên plugin; đặt template Admin dưới namespace riêng và kiểm tra URL sau khi export, không suy từ annotation đơn lẻ.
- Có ba bề mặt lệnh dễ nhầm: [SDK](https://youngmonkeys.org/ezyplatform/guides/ezyplatform-sdk-commands?lang=vi) dùng `ezy.sh`/`ezy.bat` để scaffold, `link`, đồng bộ dependency, `package`/`export`; [CLI runtime](https://youngmonkeys.org/ezyplatform/guides/ezyplatform-cli-commands?lang=vi) quản lý module, phiên bản và server; `./scripts/ezy` của repo là wrapper CLI CPPAI đã pin, theo README của repo. Không xem lệnh ở ba nơi là tương đương.
- Luồng phát triển được hướng dẫn: SDK/runtime đúng phiên bản → tạo/import Maven project → startup test theo module → build/export → cài/kích hoạt → restart khi quy trình module yêu cầu. `link` một plugin đã cài bổ sung dependency Maven và package cần scan trong startup test; chỉ link khi có nhu cầu thật, kiểm tra version phía runtime và classpath.
- Stack mục tiêu có EzyPlatform **1.5.9**, **Java 11**, **MySQL 8.0**, EzyArticle **1.5.6**. Cổng host mặc định bind loopback; runtime và DB có volume riêng. Các bước cài tay Ubuntu/Windows trên website không thay thế quy trình compose đã pin. FAQ yêu cầu **tương thích từ Java 8 nếu đưa lên Marketplace**; runtime nội bộ Java 11 không tự chứng minh điều kiện này.

## Các điểm mở rộng cần nắm trước khi viết plugin

| Việc | Điểm mở rộng ghi trong tài liệu | Giới hạn / quyết định cho dự án |
| --- | --- | --- |
| Xác thực Admin | `@Authenticated`, `@AdminId`, `@AdminRoles AdminRolesProxy`, `@EzyFeature` | Danh tính Admin khác user. `isAccessible` hỗ trợ UI; ẩn nút không phải kiểm soát truy cập. |
| Xác thực Web | `WebAuthenticationInterceptor`, `@Authenticated`, `@UserId`; ví dụ override `needToCheckPermission()` | Hướng dẫn nói Web mặc định không bắt buộc login. Phải thử tích hợp với theme/plugin login hiện có và kiểm tra tất cả route; feature permission không thay quan hệ membership. |
| UI Admin | Thymeleaf `View`; menu + i18n; `ViewDecorator` thêm biến mặc định bằng `setVariableIfAbsent`; `rightToolbarToolFragments` render fragment `:: content` | Tránh query DB mỗi lần render menu chung. `additionalMessageKeys` đưa key sang JS; tải asset nặng chỉ trên view cần. `previousScreen` dùng để giữ luồng điều hướng, không chấp nhận redirect tùy ý từ client. |
| UI Web | Template/fragment, hàm `ezyweb` và global exception/error handler | Các helper format, lỗi form, i18n không thay validation phía server. SPA chỉ nên là lớp UI; giữ API và quyền độc lập theme. |
| Tìm kiếm | `AdminSearchService` trả `SearchResultModel`; global search tổng hợp kết quả của các plugin tham gia | Dùng cho công cụ vận hành nếu truyền được ngữ cảnh quyền. Search công việc Web phải áp dụng scope ngay trong query, cả khi autocomplete/count. |
| Danh sách | `Filter → PaginationParameter → Converter → Repository → Service` hỗ trợ token cursor/offset, tạo JPQL; devtools có generator | Chọn cursor cho backlog/feed; sort có khóa phụ ổn định; token base64 không phải chứng thực, luôn xác thực scope/filter/sort và giới hạn page size. `Reactive.multiple()` phù hợp gom lookup độc lập theo lô, không thay transaction. |
| Media | `MediaControllerService`, `MediaUpDownloader`, UI media modal, hook event; có phân loại MIME và cơ chế giảm ảnh | Với attachment riêng tư, xác minh quyền qua work item chứ không chỉ người upload. Không trả raw URL public hay dùng modal mặc định trước khi xác nhận danh sách/download không lọt scope. Kiểm thử file gốc và adapter ngoài. |
| Thông báo | `WebNotificationService`/`WebLetterService`, template nội dung và receiver; có controller service và UI mẫu | Dùng adapter sau commit; letter trong hệ thống khác email. Không trông cậy vào EzyMail sẵn có. Chỉ gửi cho người còn quyền, không gửi trùng khi retry. |
| Event nội bộ | `AdminEventHandlerManager`, `WebEventHandlerManager`, `EventHandler`/`AbstractEventHandler`, priority, `VoidEvent` | Đây là dispatch nội bộ, không phải broker/durable queue; event trả kết quả có thể dừng ở handler đầu tiên trả khác null. Giữ audit/outbox bền vững trong DB plugin. |
| Batch/biến cấu hình | `AdminDataAppender` có phân lô, checkpoint, bật/tắt/tải lại; `SettingService`/`AdminSettingService` đọc, ghi, mã hóa và quản lý cache | Hợp cho backfill/projection nếu chứng minh idempotency và chỉ một worker mỗi job. Không lưu dữ liệu nghiệp vụ từng workspace dưới setting toàn hệ thống. Cron hỗ trợ 5/6 trường, Chủ nhật là 0, không dùng cú pháp Quartz đặc biệt; xử lý timezone/DST trong thiết kế nhắc việc. |
| Liên kết public | `LinkService.saveLink`, bảng `ezy_links`, appender theo thời gian cập nhật | Pattern cho liên kết đã phát hành, không đưa URL work item riêng tư vào catalog/SEO. |
| Low-code | View schema mô tả biến template cho công cụ khám phá; `JavascriptService` chạy Rhino, có bean được expose và object result | Không cho thành viên nhập script chạy phía server. Hai điểm mở rộng này không cần cho MVP. |

Xem [mục lục](ezyplatform-guide-inventory.md) để truy ngược các hướng dẫn và tên file.

## Vận hành, dữ liệu và xuất bản

- [Hướng dẫn cài đặt](https://ezyplatform.com/installation-guide) nêu 1 CPU/2 GB là mức tối thiểu, khuyến nghị 2 CPU/4 GB, Java 8+ và MySQL; local không cần domain, triển khai có thể dùng domain Admin và Web riêng. [FAQ](https://ezyplatform.com/faq) dẫn `/modules/add`, rồi cài, kích hoạt và khởi động lại; danh sách công khai không có nghĩa tất cả plugin có sẵn trong stack.
- [FAQ](https://ezyplatform.com/faq) còn nêu index có sẵn chỉ là mặc định; tối ưu theo truy vấn thật. Module release cần đa ngôn ngữ, tên package ngoài namespace dành riêng, không đóng gói file/JAR đã có trong core, không tự sửa dữ liệu cũ nếu chưa được chấp thuận, tránh tài nguyên không được phép phân phối và theo yêu cầu dung lượng. Hỗ trợ sử dụng thương mại **theo** [giấy phép EzyPlatform 1.0.0](https://youngmonkeys.org/licenses/ezyplatform-1.0.0.txt); không suy giấy phép core từ giấy phép Plane hay repo SDK.
- [Hướng dẫn migration](https://youngmonkeys.org/ezyplatform/guides/migrate-ezyplatform-from-server-a-to-server-b?lang=vi) tách runtime và DB dump; [nhiều instance dùng chung DB](https://youngmonkeys.org/ezyplatform/guides/install-multiple-ezyplatforms-with-a-single-database?lang=vi) cảnh báo về khóa mã hóa riêng theo instance. Multi-workspace trong một app không đồng nghĩa với nhiều cài đặt vật lý dùng chung DB. Sao lưu runtime, DB và cấu hình khóa theo quy trình bảo mật; xác minh khôi phục trên môi trường thử trước nâng cấp.
- [Thống kê](https://youngmonkeys.org/ezyplatform/guides/ezyplatform-statistics-apis?lang=vi) mô tả telemetry vòng đời runtime/module và setting `allow_send_statistics_data`; đánh giá theo chính sách của nơi triển khai. Không dùng telemetry này thay log nghiệp vụ/analytics của plugin.
- Hướng dẫn khôi phục/phần lỗi giúp phân biệt lỗi JDK, dependency thiếu/khác phiên bản, working directory, module bị cài lỗi và môi trường IDE. Các bài hạ tầng tách reverse proxy HTTPS, SSL Socket, tài nguyên/JVM và cấu hình log; với dự án này ưu tiên không mở Admin trực tiếp và không sao chép script cài production từ ví dụ.

## Phạm vi và độ chắc chắn

Đã đọc tài liệu công khai ở mức nội dung văn bản và ví dụ mã; không tương đương kiểm thử runtime, xem toàn bộ video hoặc kiểm tra nội dung cần đăng nhập/mua. Các API/pattern trong tài liệu là khả năng được ghi nhận; các quyết định “dùng cho plugin” và thiết kế Plane là **đề xuất**. Không cài/kích hoạt plugin, dựng môi trường, hay xử lý AgentKit trong phần việc này.
