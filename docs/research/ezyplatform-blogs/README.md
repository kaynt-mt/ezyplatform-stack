## What agents need to know

1. **Identify the surface you are working on.** The core includes Admin for administration, Web for end users and APIs, and optional Socket for real-time communication. Modules add business capabilities; themes determine the Web interface. Administrators and Web users have separate permission scopes. See [architecture and runtime boundaries](van-hanh.md#separate-runtimes-modules-and-applications).
2. **Choose the workflow for your environment.** Start this stack with `./scripts/up.sh`; on the first run, create a super admin at `/setup-admin`. Manual installation, distribution CLI commands, and reverse proxy examples from the blog do not replace this repository's Docker Compose setup, version pins, or backup process. Installing, activating, restarting, and applying updates are separate steps. Verify the core and dependencies first. See [installation, deployment, and Admin operations](van-hanh.md#install-deploy-and-operate-admin).
3. **Use the smallest extension that meets the need.** For content, use pages, fragments, media, or i18n if the active theme supports them. Use an EzyArticle project and follow sync → edit → preview → approve → publish → verify. For new business logic, keep the app in a separate repository, put shared logic in the SDK, choose the necessary Admin, Web, or Socket modules, and test the artifact on the intended runtime. Distinguish SDK commands from the `./scripts/ezy` wrapper. See [plugin, theme, and content development](phat-trien.md).
4. **Learn from case studies without assuming their features are defaults.** Content and SEO sites use EzyArticle and measurement tools. Shops combine E-Commerce, landing pages, and campaigns. Consulting, community, delivery, training, and game projects need their own workflows and permissions. See [industry use cases](ung-dung.md) and the [stack plugin catalog](../../plugins/README.md) to identify modules that must be installed separately.
5. **Read and verify the source before acting.** Find the article in the index, read the original and neighboring articles in the series, and cross-check the [official Guide index](../ezyplatform-guide-inventory.md) and the synced `.agents/skills/ezy-guide/SKILL.md` in the workspace. Do not treat marketing posts as API evidence, sample figures as benchmarks, or old articles as production deployment procedures. Use least privilege and do not write to production without approval.
