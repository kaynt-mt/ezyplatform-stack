## Java projects and modules

- [Create a theme or plugin project](https://ezyplatform.com/blog/tao-du-an-ezyplatform-theme-va-plugin?lang=vi): Install the runtime and SDK, add `EZYPLATFORM_SDK/bin` to PATH, and build the libraries in `ezyplatform-development` with Maven. An older SDK example uses `ezy.sh cp hello-world -g com.example -i admin-plugin,theme,web-plugin`. Import the Maven project, set the working directory to the right module, run the startup test, then export and activate the artifact in a test runtime. The article runs `bash export.sh` and inspects the ZIP in `target/project/`; follow the current skill for stack scaffold and export commands.
- [Project structure](https://ezyplatform.com/blog/cau-truc-du-an-theme-plugin-ezyplatform?lang=vi): The SDK contains shared models, entities, repositories, and services; Admin plugins serve administration, Web plugins serve APIs, and themes provide the interface. Socket plugins and apps handle real-time work and connections. Include only the modules the project needs. Do not use the theme as a substitute for plugin permissions or business logic.
- [Admin menus](https://ezyplatform.com/blog/huong-dan-lap-trinh-menu-cho-ezyplatform-admin-plugin?lang=vi): Use a `menus.properties` file per module. See the [menu guide](https://youngmonkeys.org/ezyplatform/guides/create-menus-for-admin-plugin?lang=vi) for placement, localized labels, and links. Verify routes and API permissions after exporting. Seeing a menu item does not establish that the user may modify data.
- [Plugin tables](https://ezyplatform.com/blog/tao-bang-trong-ezyplatform-plugin?lang=vi): Put SQL under the **Admin** module's `scripts` resources directory. Web and Socket do not scan it. Prefix table names with the plugin name, use `CREATE TABLE IF NOT EXISTS` for new tables, and write entities, repositories, and integration tests. Verify SQL in a development database and distinguish a schema update from rerunning a migration.
- [Internal events](https://ezyplatform.com/blog/tao-va-xu-ly-su-kien-noi-bo-internal-event-trong-ezyplatform-plugin?lang=vi): Separate the event class, manager, and handler. Another plugin's handler can receive an event within the same runtime. Events do not cross from Admin to Web or Socket or to another server. This is not a durable queue. [Data appenders](https://ezyplatform.com/blog/tao-batch-data-appender-trong-ezyplatform-plugin?lang=vi) are another option for background batch processing.

## Low-code development, pages, fragments, and APIs

- [Theme page fragments](https://ezyplatform.com/blog/su-dung-page-fragments-cac-phan-trang-cho-ezyplatform-theme?lang=vi) and [low-code setup](https://ezyplatform.com/blog/ezyplatform-low-code-chuan-bi-moi-truong?lang=vi): Before editing a Java theme, identify what content Admin can manage, where the theme assembles pages or fragments, and what needs a module. On EzyArticle sites, sync the project before editing, use the ezy-author/media/i18n/verify skills, and publish only after approval.
- [Feed real data into Ezyvora](https://ezyplatform.com/blog/huong-dan-dua-du-lieu-that-tu-ezyplatform-vao-website-ezyvora?lang=vi): Inventory mock data and map its properties to configured content or managed articles. Move over one small area at a time, keeping the UI unchanged as the data source changes. For SEO content, prefer server-rendered HTML; client-side APIs suit interactive sections that do not depend on SEO. Verify changes from Admin through to Web, including drafts, empty data, errors, and missing images, then remove remaining mocks.
- [Integrate the EzySupport API](https://ezyplatform.com/blog/huong-dan-ghep-api-ezysupport-vao-website-doanh-nghiep-ezyvora?lang=vi): Compare form fields with the existing API, keep Admin tokens out of the frontend, and verify both Web notifications and the corresponding request in Admin → EzySupport. [Blog page fragment](https://ezyplatform.com/blog/huong-dan-cai-dat-page-fragment-blog-cho-website-doanh-nghiep-ezyvora?lang=vi): Inventory fragments, reuse list and detail fragments where available, assemble them into the page, and test navigation from the list to individual articles. These steps are specific to Ezyvora and do not guarantee endpoints on every instance. Verify the actual plugins and theme and consult `ezy-guide` before calling an API.
