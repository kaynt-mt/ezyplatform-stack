# Model routing

Every Bot and Devin session follows the owner's rule: **right role, right model, best value for cost**.

| Work | Model or mode |
|---|---|
| Coding, fixing, and testing | SWE-2.1 at Max reasoning (the owner's default agent). Dispatch without specifying a mode. |
| Hard architecture and planning | Ultra |
| Research, review, and documentation | Fusion |
| Small chores (translation, status checks, short doc edits) | Lite |
| UI design | The frontend mode |

SWE-2.1 is in preview until 2026-12-22. After that date, route coding, fixing, and testing to Fusion.
